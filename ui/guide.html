Home

The wheel browses; pressing it selects. USE, OPEN or ENTER confirms a choice. Home returns to the dashboard.

Edit a mapping

  1. Open MAP and choose an app, profile and page.
  2. Click a tile or knob, then choose its action.
  3. Change its label, icon or colour. Changes save automatically; wait for Saved.
  4. Undo and Redo reverse or restore edits. Activate on CT applies the selected profile.

App connections

Start your app normally first. Moshpit uses its local control endpoint; keyboard profiles need the correct app in focus. Spotify uses Windows media controls.

TD SETUP opens mapping settings. TouchDesigner needs a compatible project and a matching profile; none is supplied as a generic default.

Optional verified launch

In your user configuration folder, apps.json can give Moshpit or TouchDesigner an absolute launch executable path and its launchSha256. Obtain the checksum with PowerShell Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Apps\Example.exe'. Only configure software you trust. After updating it, verify the new file before replacing its checksum.

No personal projects, footage or private library links are included.

Disconnect

Use the tray menu’s Quit CTserver to release the controller. Closing the window only hides it.
